# Работяга iOS: этап 1 (Шабашка)

## Согласованное назначение

Работяга на Hermes Agent: личный помощник, работающий с Telegram, задачами, компьютерами и поиском заказов. Направления заработка: Telegram-боты, Mini Apps, сайты, ИИ-агенты, Python, автоматизации и интеграции. Поиск заказов на YouTube-продюсирование, видеопроизводство и услуги HOOK agency исключён.

## Первый пользовательский сценарий

1. Агент находит заказ через разрешённые источники.
2. Проверяет источник, бюджет, соответствие специализации и дубли.
3. В iOS в разделе «Шабашка» отображается карточка с объяснением рекомендации.
4. Свайп влево = пропустить; вправо = интересно, подготовить отклик; кнопка сохранения = отложить.
5. Выбранные заказы видны в списке «Задачи».
6. После выбора агент готовит **черновик**, предлагает подходящие кейсы и ждёт отдельного подтверждения перед отправкой.

**Не допускается:** автоматическая отправка откликов/сообщений, принятие заказа, изменение цены, покупка или публикация без явного согласия пользователя. Не обходить правила источников и не придумывать факты о навыках или кейсах.

## Текущий прототип

SwiftUI, iOS 15+, без сторонних зависимостей. Четыре вкладки: Чат, Шабашка, Задачи, Настройки. На первом этапе Шабашка работает с тремя **явно демонстрационными** карточками. Решения сохраняются локально через AppStorage. Чат не изображает связь с Hermes, пока она не реализована.

## Следующий этап (после тестовой IPA-сборки)

- Защищённый транспорт с Hermes (аутентификация, TLS, Keychain).
- API выдачи предложений: id, title, budget, source, source_url, description, reason, tags, timestamps и статусы.
- Синхронизация свайпов без дублей и повторной отправки; локальная очередь при отсутствии сети.
- API генерации черновика отклика и явное подтверждение отправки.
- Фильтры, история отказов и корректировка рекомендаций.
- Реальный чат и статусы задач.

Никаких действующих учётных данных или внутренних адресов в публичном репозитории.
