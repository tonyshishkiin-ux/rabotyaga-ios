# Работяга iOS — правила для агентов

## Проект и стек

- Это нативное iOS-приложение на SwiftUI. Не переводить его на Expo, React Native,
  UIKit или другой стек без отдельного архитектурного решения владельца.
- Проект: `Rabotyaga.xcodeproj`, схема: `Rabotyaga`, bundle ID:
  `ru.rabotyaga.app`.
- Минимальная версия: iOS 15.0; Swift language mode: Swift 5.
- Зависимостей Swift Package Manager, CocoaPods и сторонних UI-фреймворков нет.
- Текущий этап — минимальное приложение для бесплатной установки на iPhone.
  Будущие Hermes-интеграции не реализовывать до подтверждённого запуска IPA.

## Навыки и справочные материалы

- Для iOS/HIG-задач доступен глобальный навык `mobile-ios-design` в
  `~/.codex/skills/mobile-ios-design`.
- В Codex также доступен bundled-навык `figma-swiftui` для явных задач перевода
  между Figma и SwiftUI.
- Не применять примеры API из навыков вслепую: проверять availability относительно
  iOS 15. Например, новый `Tab` API нельзя использовать без поднятия deployment
  target или availability fallback.
- Правила интерфейса находятся в `docs/DESIGN_SYSTEM.md`; команды разработки и
  ограничения окружения — в `docs/DEVELOPMENT.md`.

## Дизайн и архитектура

- Сохранять нативное поведение SwiftUI, системные контролы, SF Symbols,
  семантические шрифты и цвета.
- Основная тема тёмная. Не кодировать системные цвета числовыми RGB-значениями,
  кроме утверждённых брендовых токенов.
- Поддерживать Dynamic Type, VoiceOver, Reduce Motion, Increase Contrast,
  безопасные области, клавиатуру и touch targets не меньше 44×44 pt.
- Проверять интерфейс как минимум на iPhone 15 Pro и компактной ширине.
- Не размещать основные действия у верхнего края, если их можно безопасно
  перенести в доступную одной рукой область.
- До появления нескольких экранов не вводить сложную архитектуру. При росте
  проекта разделять код по feature-модулям и держать UI, состояние и транспорт
  раздельно. Не добавлять глобальные singleton-сервисы.

## Безопасность

- Не добавлять в Git Apple ID, пароли, provisioning profiles, сертификаты,
  SSH-ключи, Hermes/Telegram-токены, GitHub secrets, внутренние адреса и личные
  данные.
- Apple-авторизация и подпись выполняются только локально владельцем. CI собирает
  неподписанный артефакт и не получает Apple credentials.
- Для будущего Hermes API использовать TLS, Keychain для пользовательских
  секретов, короткоживущие токены и минимальные разрешения. Не хранить секреты в
  `UserDefaults`, исходниках, логах или analytics events.
- Новую зависимость добавлять только после проверки владельца, лицензии,
  актуальности, минимальной iOS и конкретной необходимости.

## Git и область изменений

- Перед правкой проверять `git status`, инструкции проекта и затрагиваемые файлы.
- Сохранять пользовательские и несвязанные изменения. Не применять destructive
  Git-команды и не переписывать историю.
- Не публиковать код, не добавлять remote и не делать push без явного разрешения.
- Не менять рабочий Hermes и другие соседние проекты из этого репозитория.

## Проверка изменений

Выполнять минимальный достаточный набор, честно отмечая недоступные проверки:

1. `git diff --check` и просмотр полного diff.
2. Проверка JSON/YAML/scheme/project-файлов соответствующими парсерами.
3. На современном Mac с Xcode 26.5 или совместимым — сборка схемы для iOS
   Simulator и generic iOS Device.
4. Для изменения UI — запуск `.maestro/smoke.yaml` на iOS Simulator, ручная
   проверка Dynamic Type/VoiceOver и скриншоты iPhone 15 Pro.
5. Для release-кандидата — `bash scripts/build_unsigned_ipa.sh` и проверка, что
   артефакт содержит `Payload/Rabotyaga.app` и не содержит provisioning profile.

Windows не может собирать iOS. Старый MacBook на Monterey без Xcode также не
является доказательством сборки. Успех сборки в CI не считать успешной установкой
на физический iPhone.

## IPA и бесплатная подпись

- Основной CI: `.github/workflows/build-unsigned-ipa.yml` на `macos-26` с
  Xcode 26.5. Резерв: `codemagic.yaml` на бесплатном `mac_mini_m2`.
- Оба пути используют `scripts/build_unsigned_ipa.sh` с отключённой подписью.
- Неподписанный IPA локально подписывается и устанавливается через Sideloadly.
  Бесплатный Apple-аккаунт ограничен тремя приложениями; подпись действует семь
  дней и требует повторной подписи/refresh. На iOS 16+ нужен Developer Mode.
